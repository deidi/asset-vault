Engineered for Creative Speed

A full-featured digital asset manager built for editors, 3D artists, designers, and developers.

In-Place Multi-Folder Libraries

Mount any number of local or network directories. Files are indexed in-place without moving or duplicating them across your drive.

Native Windows Explorer Integration

Highlight exact files with Reveal in Explorer, perform safe in-place renames, and delete files to the Windows Recycle Bin with send2trash.

High-Def Video & PDF Thumbnails

Instant visual previews with Windows Shell video keyframe extraction, pypdfium2 PDF rendering, and Pillow image caching.

Smart Auto-Tagging & AND-Filtering

Automatic assignment of #ext, #filename, #year, and parent folder tags with full multi-tag intersection queries.

Full-Screen Interactive Previewer

Deep-zoom, pan, and rotate image viewer, multi-speed HTML5 video player, audio playback, and PDF document reader.

100% Offline & Private

Runs entirely on your local machine with zero external cloud dependencies, telemetries, or data collection.
