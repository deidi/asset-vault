# Security Policy

## Supported Versions

Security updates are actively applied to the latest release of AssetVault.

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

---

## Reporting a Vulnerability

We take the security of AssetVault seriously. If you discover a security vulnerability, please report it responsibly:

1. **Do not open a public GitHub issue** for undisclosed security vulnerabilities.
2. Instead, report security issues via:
   - **GitHub Private Vulnerability Reporting**: Navigate to **Security ➔ Report a vulnerability** on the repository.
   - Or open a private inquiry with the maintainers.

### What to Include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue or a proof-of-concept (PoC).
- Your suggested remediation or fix (if available).

### Response Timeline:
- We acknowledge receipt of vulnerability reports within **48 hours**.
- We will provide a timeline for validation and release of a patch.
- Once fixed, security advisories will be published alongside the patched release notes.

Thank you for helping keep AssetVault and its users secure!
